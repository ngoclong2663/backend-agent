# Sample files

Small files of our own (public domain, CC0) that the generated apps' mocks and seeds, and the evaluation's walker,
use where a file field needs something to show or to upload.

- `placeholder.png`: a 1×1 transparent PNG (Story 28.6: the walker's upload when nothing better fits a field).

Epic 29 adds the sample media (a short video, a tone, subtitle tracks and a poster) made by `make sample-media`.
