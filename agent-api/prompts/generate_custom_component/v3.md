## What the section renderer passes
The site renders sections from `src/content/site.json` with `SectionRenderer`. Besides the props above, a component
bound to data receives (all optional, types in `@/components/renderer/site`):

- `binding?: TBinding`: the section's operation (`operationId`, `action` "list" or "get", `params`, `link`)
- `items?: TRecord[]`: the records of a content collection (static sites)
- `columns?: TColumn[]`: the fields to show, each `{ key, label, format }`
- `states?: TStates`: the texts for loading, empty and error
- `children?: ReactNode`

Read data only through `useSectionRecords(items, binding)` from `@/components/renderer/use-section-records`: it
returns `{ records, record, isLoading, error }` (`record` for get operations) and resolves `$route.<name>`
parameters. Show values with `formatValue(value, column.format)` from `@/components/sections/format`, wrap data in
`QueryState` from `@/components/sections/QueryState`, link a record to its page with
`recordHref(binding?.link, record)`. Mutations: `useOperationMutation(operationId)` from
`@/components/renderer/bindings`. The sample props are in `{{ spec_path }}`.

## Conventions (nextjs-skills; the isolated checks enforce them)
- `"use client";` first when it uses hooks, state or events.
- Named React imports only, never `import * as React`; `type`, never `interface`; standalone types `T`-prefixed,
  the props type `{{ name }}Props`.
- Colours from the design tokens only (`bg-primary`, `text-muted-foreground`, `border-border`), never hex/rgb.
- No `fetch` or other network calls; at most 30 lines of logic before the component's `return`.
- Never call `setState` synchronously in a `useEffect` body. Compute derived values during render, initialise state lazily (`useState(() => ...)`), or reset state by giving a child component a `key`.
- Do not write `useMemo`, `useCallback` or `React.memo`: the React Compiler memoises. If you do write one, its dependency list must list every value the callback reads.
- Data from `useSectionRecords` is a new array on every render: never use it as an effect dependency to copy it into state.
