# Story 29.2 — Sample media for mocks, seeds and the walker

**Epic:** [29 — Media fields](epic29_media_fields.md) · **Requirements:** FR-43 · **Depends on:** 29.1

## User story

As someone trying a generated app on mocks or in a preview, I want media fields to play something real, so that
every screen with a player can be seen working before anyone uploads.

## Context

- Mocks keep uploads as blob or data URLs and read fixture values as they are (`src/mocks/plugins.ts`, `fileUrls`).
- The smoke seed uploads each seeded file value as an object, and keeps outside `http(s)` links as they are
  (`storage.py`, `_stand_in`, `outside_url`).
- Epic 27's stock photos fill image seeds; there is no stock source for video or audio (D6).

## Steps

1. **The files.** `scripts/sample-media.sh` (dev tool, `make sample-media`; ffmpeg in a one-off container, so no image
   gains ffmpeg) generates them once, and they are committed: `sample.mp4` and `sample.webm` (6 s, 640×360, a moving test pattern in neutral tones, a silent
   track), `sample.mp3` and `sample.ogg` (6 s, a soft tone), `sample.en.vtt` and `sample.<second language>.vtt` (three
   cues each), and a poster `sample-poster.jpg`. Each under 400 KB. They live in the base's `public/samples/` and in
   the agent's `templates/samples/` for seeds. Their licence (our own, CC0) is noted in the README of the folder.
2. **Mocks:** a seeded media field without a value of its own reads `/samples/sample.<ext>` by kind; subtitle tracks
   read the VTT files with their language.
3. **Seeds:** the backend seed uploads the sample file of the field's kind for each seeded media value (the content
   type of the file), so previews play it; the seed's own outside link is kept as for images.
4. **Fixtures (code):** the contract's fixtures give each media field a sample key and each track entity one row per
   sample language.
5. Tests: fixtures for a synthetic media spec; the mocks' `fileUrls` for each kind; the seed's upload content types.

## Acceptance criteria

- [ ] On mocks and in a preview, every seeded media field plays its sample file, with subtitles where the spec has
      tracks.
- [x] The sample files are generated by our script, are small, and carry a licence note.

## Verify

`make sample-media` (once), `make frontend-base`, `make runner-node`, `make test`, `make up` with the synthetic media spec as a dynamic app.

the field's kind (`plugins.json` fields now carry `kind`), a subtitle key with the sample of its language. Seeds: the

track entity gets one row per sample language with its language set and a `.<lang>.vtt` key. Tests:
`test_media_fields.py` (fixtures, objects' bytes, the seed artifact's shape, the samples' sizes, the scaffold copying
them for the media app and not for the workshop app). The preview playing them is checked in 29.6.
